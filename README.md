# Lista de Tarefas

Aplicativo Android para Wear OS (relógio) de lista de tarefas.

## Descrição

Aplicativo desenvolvido para Android Wear OS que permite gerenciar uma lista de tarefas diretamente no relógio.

## Tecnologias

- Android SDK
- Kotlin
- Gradle
- Material Design

## Requisitos

- Android Studio
- Android SDK 30+
- Target SDK 36

## Como executar

1. Clone o repositório
2. Abra o projeto no Android Studio
3. Conecte um dispositivo Wear OS ou use um emulador
4. Execute o aplicativo
